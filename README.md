AI FoodBridge is a web-based sustainability project designed to reduce food waste and fight hunger by connecting food donors with NGOs and needy communities.
It is built as part of the UN Sustainable Development Goal 2: Zero Hunger initiative.

The system uses a simple AI logic simulation to analyze donated food, estimate freshness, assign priority levels, and suggest suitable NGOs for distribution.

🚀 Features
🍱 Food donation form (user input system)
🤖 AI-based food analysis (rule-based AI simulation)
📍 NGO recommendation system
📊 Impact dashboard (meals saved, waste reduced, people helped)
🌐 Multi-page responsive website
💡 Clean UI for better user experience
🧠 AI Concept Used

This project uses rule-based AI logic to simulate decision-making:

Food type classification (fruits, vegetables, cooked food)
Freshness estimation logic
Priority detection based on quantity
NGO matching logic

This demonstrates how AI can support sustainability decisions in real-world systems.
